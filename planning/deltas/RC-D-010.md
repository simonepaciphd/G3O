Keep the actual returned code in provenance. Apply the existing R-041/R-081 downgrade rules to the affected code and record missing probability as the cause. The special page-verdict rule still retains the verdict and tags it downgraded. Existing non-page mappings remain as signed; do not use a generic unknown substitution for every item. A measured probability of exactly 0.8 passes; missing probability is not a measured value below the bar.

Mechanical coders and signed rule-set values remain typed not-applicable where already approved; they are not provider omissions. No new retry, paid call or publication authority follows. If an item has no signed applicable downgrade mapping, report that specific gap before inventing one.
