### F. Extractor access through the Stanford AI API Gateway (E4; under study, not yet ruled)

Facts checked 2026-10-29:
- **Haiku 5.5 is available.** "Enabled the Anthropic Claude Fable 5.1 and Claude Haiku 5.5 models as an option for virtual API access" (UIT release notes, 2026-10-15).
- **It is a LiteLLM proxy with an OpenAI-style `/v1/chat/completions` interface**, not the native Anthropic API (rcpedia post, undated; release notes).
- **No Batch:** "The AI API Gateway does not support 'batch mode'" (rcpedia).
- **Slower:** "often significantly slower than using commercially available models" (rcpedia).
- **No published rate limits.**
- **Billing:** monthly to a PTA. The rates page needs a Stanford login, so any markup is UNVERIFIED.
- **Usage detail:** "detailed breakdowns of model use and token numbers are not provided" (rcpedia). A usage-metrics endpoint was added 2026-04-28 (release notes), so this may be out of date.
- **Access:** open to faculty and staff with a valid PTA. Request through the ServiceNow form "Request the creation of a new API key", naming the models.
- **Data risk:** approved for High Risk data (UIT service page, modified 2026-09-25).

Consequences for this delta:
- **The Gateway cannot run Batch,** so ruling B ("batch for full run") cannot be met through it.
- **Reasoning effort:** whether "medium effort" passes through LiteLLM's OpenAI interface to Haiku is UNVERIFIED. T-002 must confirm it.
- **Cost accounting:** the pipeline's cost monitor must count tokens from response `usage` fields, not from vendor dashboards.
- **Code:** the Anthropic client in A becomes an OpenAI-compatible client pointed at the Gateway base URL. Existing OpenAI code paths may be reusable (T-022 to confirm).
